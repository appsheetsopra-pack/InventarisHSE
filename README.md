# INVENTARIS HSE — HSEGA 2026

**PT Solusi Prima Packaging**

Portal Inventaris dan Inspeksi APAR & P3K. Tema merah marun profesional dengan ikon K3 vektor.

## Instalasi GitHub Pages
1. Buat repository publik, misalnya `sopra-inventaris-apar-p3k`.
2. Upload **index.html** dan **logo-k3.svg** ke root repository (jangan unggah file ZIP).
3. Buka Settings → Pages → Deploy from a branch → main → /(root) → Save.
4. Buka `https://USERNAME.github.io/sopra-inventaris-apar-p3k/` sesudah deploy berhasil.

## Menu
- Dashboard Utama: statistik inventaris, diagram status aset dan aktivitas terakhir.
- Inventaris APAR/P3K: kode, lokasi, plant, status Baik/Kadaluarsa/Sedang Direfill, tanpa PIC.
- Inspeksi APAR: nama dan lokasi di atas, enam poin pemeriksaan, foto di akhir.
- Inspeksi P3K: nama dan lokasi di atas, kondisi kotak, 18 item perlengkapan menurut tipe A/B/C, foto di akhir.
- Riwayat & Ekspor: CSV untuk Excel, backup JSON, impor dan cetak PDF.

**Penting:** Semua data masih disimpan lokal di browser (`localStorage`, kunci `sopra_apar_p3k_v1`), bukan database bersama. Hasil dari perangkat berbeda tidak otomatis terkumpul. Backup data secara rutin. Foto terbatas hingga 500 KB. Data pada dashboard hanya data lokal sebenarnya, tanpa contoh fiktif.
